# 104. 实战：生产就绪的平台

Day 103 讲了部署与运维。本节动手**整合监控、评估、安全、性能优化、部署**，实现**生产就绪的平台**：指标与结构化日志、RBAC 与审计、缓存与限流、容器化与健康检查。完整可运行代码见 **`week15/105_code/production_platform_demo.py`**，配套测试与镜像构建见 **`week15/105_code/test_production_platform.py`**、**`week15/105_code/Dockerfile`**、**`week15/105_code/docker-compose.yml`**。

## 一、整合监控、评估、安全、性能优化、部署

### 1. 监控集成

- **Langfuse**：在 Runtime 中接入 Langfuse Callback，自动记录 trace、成本、性能。
- **指标收集**：用 Prometheus 或自定义指标收集器，统计请求量、延迟、错误率、成本。
- **日志**：用 structlog 记录结构化日志，包含 trace_id，支持分布式 trace。

### 2. 评估集成

- **评估指标**：收集任务完成率、准确性、用户满意度、成本效率。
- **测试用例**：准备测试数据集，编写单元测试、集成测试、端到端测试。
- **A/B 测试**：实现流量分配、指标收集、统计分析，支持 Agent 策略、路由策略、模型版本的对比。

### 3. 安全集成

- **API 密钥管理**：密钥存储在环境变量或密钥管理服务，支持密钥轮换。
- **用户权限**：实现 RBAC 模型，Gateway 中检查用户权限，控制资源访问。
- **数据隔离**：多租户数据隔离，会话与资源隔离。
- **审计日志**：记录所有敏感操作，存储在审计表或日志文件。

### 4. 性能优化集成

- **缓存策略**：实现结果缓存、LLM 响应缓存、工具结果缓存（用 Redis）。
- **并发控制**：实现请求队列、限流（令牌桶）、超时控制。
- **数据库优化**：添加索引、使用连接池、优化查询。
- **LLM 调用优化**：支持批处理、流式响应、模型选择。

### 5. 部署集成

- **容器化**：Dockerfile、docker-compose.yml、Kubernetes 部署文件。
- **配置管理**：环境变量、配置文件、密钥管理。
- **健康检查**：实现 `/health` 端点，检查应用与依赖状态。
- **回滚策略**：保留旧版本，支持快速回滚。

## 三、完整可运行示例说明

### 1. 脚本结构（week15/105_code/production_platform_demo.py）

| 模块 | 说明 |
|------|------|
| **MetricsCollector** | 请求量、延迟分位数、错误率、成本、按 agent/error_type 分组 |
| **structured_log** | 结构化 JSON 日志，含 trace_id、user_id、agent_id、latency_ms |
| **TokenBucketRateLimiter** | 令牌桶限流，Gateway 入口校验 |
| **ResponseCache** | 响应缓存（user_id+message hash，TTL），Gateway 内查/写 |
| **AuditLog** | 审计记录（user_id、action、agent_id、session_id、trace_id） |
| **check_agent_access** | RBAC：USER_ALLOWED_AGENTS 白名单，Gateway 中校验 |
| **Gateway.handle_request** | 生成 trace_id → 限流 → 缓存 → 会话 → 路由 → RBAC → Runtime → 指标/审计/缓存写回 |
| **health_check** | 返回 status、agents、metrics 快照；Web 暴露 /health、/metrics |
| **Runtime** | run_general / run_deep_research / run_chatbi（与 Week 14 一致） |

### 2. 运行方式

**本地开发**（在项目根目录，依赖见 `pyproject.toml` 或 `week15/105_code/requirements.txt`）：
```bash
# 配置 .env 或环境变量
export OPENAI_API_KEY=...

# CLI
python week15/105_code/production_platform_demo.py --channel cli

# Web（Flask，/api/chat、/health、/metrics）
python week15/105_code/production_platform_demo.py --channel web
```

**测试**：
```bash
pytest week15/105_code/test_production_platform.py -v
```

**Docker 构建与运行**（在项目根目录）：
```bash
docker build -t agent-platform-week15 -f week15/105_code/Dockerfile .
docker run -p 5000:5000 -e OPENAI_API_KEY=xxx agent-platform-week15
```

**Docker Compose**（在项目根目录）：
```bash
export OPENAI_API_KEY=xxx
docker-compose -f week15/105_code/docker-compose.yml up --build
```
